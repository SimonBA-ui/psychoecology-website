# Psychoecology website

Public source for `psychoecology.com`.

The Russian conversation-first page presents «Цифровой рестарт» as the flagship offer and «Анализ повторяющегося поведения» as an optional paid first step. Contact is handled through a protected Formspree form, with Calendly as a secondary route. Its implementation is tracked in [#9 - Publish the Digital Reset and Mapping landing page](https://github.com/SimonBA-ui/psychoecology-vault/issues/9).
